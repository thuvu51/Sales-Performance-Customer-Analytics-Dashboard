# 📊 Sales Performance & Customer Analytics Dashboard

## 📌 Overview
This project is an interactive **Power BI dashboard** built to analyze **sales performance, product trends, and customer behavior**.  
It enables stakeholders to monitor key metrics and gain actionable insights for business decision-making.

---

## 🎯 Objectives
- Track key business KPIs: **Revenue, Profit, Orders, Return Rate**  
- Analyze **product performance** and identify high-return items  
- Understand **customer segmentation and purchasing behavior**  
- Provide an interactive tool for **data exploration and insights**

---

## 🗂️ Data Model
The dataset is structured using a **star schema** for optimal performance and scalability.

### Fact Tables
- Sales Data  
- Returns Data  

### Dimension Tables
- Customer Lookup  
- Product Lookup  
- Product Categories & Subcategories  
- Calendar Lookup  
- Territory Lookup  

---

## 📈 Dashboard Features

### 1. Executive Dashboard
- KPIs: Revenue ($24.9M), Profit ($10.5M), Orders (25.2K), Return Rate (2.2%)  
- Revenue trend over time  
- Orders by product category  
- Monthly performance comparison  

### 2. Product Analysis
- Product-level performance (orders, revenue, return rate)  
- Profit trend and return trend  
- Price adjustment simulation  

### 3. Customer Insights
- Segmentation by income level and occupation  
- Weekly customer trends  
- Top customer identification  
- Revenue per customer  

---

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development & visualization

## 📊 Key Insights
- Accessories generate the highest number of orders  
- Some products have higher return rates  
- Revenue shows a strong upward trend  
- High-income and professional customers contribute the most revenue  

---

## 🚀 How to Use
1. Download the `.pbix` file  
2. Open with **Power BI Desktop**  
3. Use filters to explore:
   - Time  
   - Product category  
   - Customer segments  
4. Navigate between pages for deeper insights
